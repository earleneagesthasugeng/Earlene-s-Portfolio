Project 03 / 06

Tomato Leaf Health Detection

A computer vision project that classifies tomato leaf condition to assess plant health, a key factor in harvest quality. The pipeline applies CLAHE to the L channel in LAB color space for contrast enhancement, then combines two feature extractors (HOG + HSV histogram) to capture both texture and color patterns. It started as my Streamlit prototype and was refined by teammates into the final FastAPI + React version, helping farmers monitor plant health more conveniently.

  • Python
  • FastAPI
  • React
  • TypeScript
  • Vite
  • SVM
  • HOG + HSV
  • Streamlit
